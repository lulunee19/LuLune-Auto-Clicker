Stop zones — how does it work?

These options stop the clicker as soon as the mouse enters a danger zone (menu, screen corner, inventory…). Enable what you need, then test at a low CPS. Values are in pixels from the screen edge.

Corner stop

If the cursor enters a square at a screen corner, the clicker stops. Useful to panic toward a corner and stop without hunting for the hotkey.

Edge stop

Same idea on the screen edges (top/bottom/left/right strips). Raise the values for a wider zone, lower them if it stops too often.

Custom stop zones

Draw a rectangle anywhere on the screen. As soon as the cursor enters it while clicking, LuLune stops. Enter = confirm the drawing, Esc = cancel. Keep the toggle ON so the zone stays active.

No zones yet — click “Draw a zone” to create one.
Click points

Chains clicks at precise positions (menus, UI buttons, farm). Turn the mode ON, add points, then start the clicker normally: LuLune clicks each point one after another.

  1. Click Start picking.
  2. Place the cursor where you want, then right-click to record the point.
  3. Repeat for each position. Press Esc to leave pick mode.
  4. Set the Click points toggle to ON, then start with your hotkey.
No click points yet. Use right-click while in pick mode.

LuLune AutoClicker

A short tour of the new features to get started.

  1. Advanced — set CPS, the button (Left/Middle/Right), and the hotkey.
  2. Toggle or Hold — Toggle = press for ON/OFF · Hold = click only while the key is held.
  3. Zones — corners, edges, or draw a custom zone for an emergency stop.
  4. Appearance — Green/Blue/Red/Light themes + background image from your PC.
  5. Macros & presets — record combos, import/export, add game profiles.
  6. Discord — in Community, click to copy LuLune0193.
