Zones d’arrêt — comment ça marche ?

Ces options coupent le clicker dès que la souris entre dans une zone dangereuse (menu, coin d’écran, inventaire…). Activez ce dont vous avez besoin, puis testez avec un CPS bas. Les valeurs sont en pixels depuis le bord de l’écran.

Arrêt coin

Si le curseur entre dans un carré au coin de l’écran, le clicker s’arrête. Utile pour paniquer vers un coin et stopper sans chercher le raccourci.

Arrêt bord

Même idée sur les bords de l’écran (bandeau haut/bas/gauche/droite). Montez les valeurs si vous voulez une zone plus large, baissez-les si ça coupe trop souvent.

Zones d'arrêt personnalisées

Dessinez un rectangle n’importe où sur l’écran. Dès que le curseur y entre pendant le clic, LuLune s’arrête. Entrée = valider le dessin, Échap = annuler. Pensez à laisser le toggle ON pour que la zone soit active.

Aucune zone pour le moment — cliquez « Dessiner une zone » pour en créer une.
Points de clic

Enchaîne des clics à des positions précises (menus, boutons UI, farm). Activez le mode ON, ajoutez des points, puis démarrez le clicker normalement : LuLune clique chaque point l’un après l’autre.

  1. Cliquez Commencer à choisir.
  2. Placez le curseur où vous voulez, puis faites un clic droit pour enregistrer le point.
  3. Répétez pour chaque position. Échap pour quitter le mode choix.
  4. Passez le toggle Points de clic sur ON, puis démarrez avec votre raccourci.
Aucun point de clic pour le moment. Utilisez le clic droit pendant le mode choix.

Petit tour des nouveautés pour bien démarrer.

  1. Avancé — réglez les CPS, le bouton (Gauche/Milieu/Droit) et le raccourci.
  2. Bascule ou Maintien — Bascule = appui pour ON/OFF · Maintien = cliquer seulement tant que la touche est enfoncée.
  3. Zones — coins, bords, ou dessinez une zone perso pour couper le clicker en urgence.
  4. Apparence — thèmes Vert/Bleu/Rouge/Clair + image de fond depuis votre PC.
  5. Macros & préréglages — enregistrez des combos, importez/exportez, ajoutez les profils jeux.
  6. Discord — dans Communauté, cliquez pour copier LuLune0193.
