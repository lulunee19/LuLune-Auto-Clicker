Notes de mise à jour · v1.4.1

Grosse passe moteur (v1.4.0) + polish d’interface, Discord Presence, opacité et stabilité des raccourcis (v1.4.1). Vos stats personnelles restent dans AppData — le ZIP est propre pour vos potes.

v1.4.1 — Opacité d’interface (10→100 %)

Nouveau curseur dans Apparence : baissez l’opacité des panneaux, de la barre de titre et de la barre de statut pour laisser vraiment transparaitre votre image de fond. À 10 % l’UI devient très translucide ; à 100 % elle reste solide. Combinable avec flou des panneaux et visibilité de l’image.

v1.4.1 — Couleurs depuis l’image (vrai gris / vraie teinte)

Bug corrigé : les thèmes écrasaient la palette de l’image et les boutons gardaient du vert en dur. Maintenant une photo grise colore toute l’interface (Démarrer, bordures, toggles, lueurs). Image colorée → accents de la photo. Option « Couleur personnalisée » avec cercle chromatique, teinte et hex pour forcer une couleur.

v1.4.1 — Discord Rich Presence (LuLuneAutoClicker + logo)

Dans l’app : Client ID uniquement + boutons « Ouvrir le portail » / « Ouvrir le fichier logo ». Le titre « Joue à LuLuneAutoClicker » et le logo se règlent dans le Discord Developer Portal (nom de l’app + Art Asset nommé exactement logo). Le lien du site sera branché plus tard. Statut Idle / Clicking · CPS en live.

v1.4.1 — Raccourcis, fenêtre AutoClick, macros

Pendant la capture d’une nouvelle touche, F6 / Panic / Pause / macros sont désactivés (Échap annule). Fenêtre plus compacte uniquement sur la vue AutoClick (icône souris). Macros : tutoriel en 4 étapes + ▶ Jouer. Hints Ctrl/Cmd selon Windows, macOS ou Linux — plus de texte mélangé.

v1.4.0 — Moteur : rampe, rafale, pixel, failsafe, timer

Rampe CPS (monte de X à Y sur N secondes). Rafales (N clics puis pause). Filtre pixel (ne clique que si la couleur sous le curseur match). Failsafe si souris immobile. Minuteur de session. Confirmation avant un CPS trop élevé. Panic F12 / Pause F7.

v1.4.0 — Sauvegardes, objectifs, overlay, FR/EN, minimal

Plusieurs slots de réglages complets. Objectifs jour / session. Overlay 4 coins + opacité, masquable en pause. Mode interface Minimal. Langue FR/EN. Sons, réduction auto au démarrage du clic. Discord : LuLune0193.

Lancer l’app

Téléchargez le ZIP de votre système, dézippez, puis lancez.

Windows

  1. Téléchargez LuLuneAutoClicker-Windows.zip
  2. Dézippez l’archive
  3. Lancez Launch-Windows.vbs (recommandé) ou LuLuneAutoClicker.exe
  4. Si SmartScreen : Infos complémentaires → Exécuter quand même

macOS

  1. Téléchargez LuLuneAutoClicker-macOS.zip
  2. Dézippez, puis double-cliquez Open-macOS.command
  3. Réglages → Confidentialité → Accessibilité → autorisez LuLune AutoClicker

Linux

  1. Téléchargez LuLuneAutoClicker-Linux.zip
  2. Dézippez, puis chmod +x Launch-Linux.sh et ./Launch-Linux.sh
  3. Préférez une session X11 / XWayland

Les builds macOS et Linux doivent être générés sur la machine cible (modules natifs souris / clavier).

Tutoriels

Discord Rich Presence, logo avec majuscules, et lancement sur chaque OS.

Discord Rich Presence (nom + logo)

Pour voir LuLuneAutoClicker (avec majuscules) et le logo vert à la place du « ? ».

  1. Ouvrez le Discord Developer Portal → votre application.
  2. Nommez l’application exactement LuLuneAutoClicker (General Information → Name). C’est le titre « Joue à … » — Discord ne le lit pas depuis l’app.
  3. Copiez l’Application ID (= Client ID).
  4. Onglet Rich Presence → Art Assets → Upload Image. Fichier : assets/discord-logo.png.
  5. Nommez l’asset exactement logo (minuscules). Attendez 1–2 min que Discord propage l’image.
  6. Dans l’app → Comportement → Discord Rich Presence : ON + collez le Client ID.
  7. Relancez Discord et l’app. Statut : logo + LuLuneAutoClicker + Idle / Clicking.

Toujours en minuscules ? Renomme l’app dans le Portal. Toujours « ? » ? L’asset logo n’est pas uploadé ou mal nommé.

Lancer sur Windows

  1. Téléchargez LuLuneAutoClicker-Windows.zip puis dézippez
  2. Double-cliquez Launch-Windows.vbs (sans console) ou LuLuneAutoClicker.exe
  3. Hotkeys : F6 start/stop · F12 panic · F7 pause

Lancer sur macOS

  1. Téléchargez LuLuneAutoClicker-macOS.zip puis dézippez
  2. Double-cliquez Open-macOS.command
  3. Réglages → Confidentialité → Accessibilité → autorisez LuLune AutoClicker

Lancer sur Linux

  1. Téléchargez LuLuneAutoClicker-Linux.zip puis dézippez
  2. chmod +x Launch-Linux.sh puis ./Launch-Linux.sh
  3. Préférez une session X11 (Wayland peut bloquer les clics)
