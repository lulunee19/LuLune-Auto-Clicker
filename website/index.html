Release notes · v1.4.1

Major engine pass (v1.4.0) plus UI polish, Discord Presence, opacity, and shortcut stability (v1.4.1). Your personal stats stay in AppData — the ZIP is clean for your friends.

v1.4.1 — UI opacity (10→100%)

New slider in Appearance: lower the opacity of panels, the title bar, and the status bar so your background image really shows through. At 10% the UI becomes very translucent; at 100% it stays solid. Combines with panel blur and image visibility.

v1.4.1 — Colors from image (true gray / true tint)

Bug fixed: themes were overriding the image palette and buttons kept hard-coded green. Now a gray photo colors the entire interface (Start, borders, toggles, glows). Colored image → accents from the photo. “Custom color” option with color wheel, hue, and hex to force a color.

v1.4.1 — Discord Rich Presence (LuLuneAutoClicker + logo)

In the app: Client ID only + “Open portal” / “Open logo file” buttons. The “Playing LuLuneAutoClicker” title and logo are set in the Discord Developer Portal (app name + Art Asset named exactly logo). Site link will be wired later. Status Idle / Clicking · live CPS.

v1.4.1 — Shortcuts, AutoClick window, macros

While capturing a new key, F6 / Panic / Pause / macros are disabled (Esc cancels). More compact window only on the AutoClick view (mouse icon). Macros: 4-step tutorial + ▶ Play. Ctrl/Cmd hints per Windows, macOS, or Linux — no more mixed text.

v1.4.0 — Engine: ramp, burst, pixel, failsafe, timer

CPS ramp (rise from X to Y over N seconds). Bursts (N clicks then pause). Pixel filter (only click if the color under the cursor matches). Failsafe if mouse is idle. Session timer. Confirmation before a CPS that is too high. Panic F12 / Pause F7.

v1.4.0 — Backups, goals, overlay, FR/EN, minimal

Multiple full settings slots. Day / session goals. 4-corner overlay + opacity, hideable on pause. Minimal UI mode. FR/EN language. Sounds, auto-minimize on click start. Discord: LuLune0193.

Still included since v1.3

Live CPS, overlay badge, Hold mode, drawable zones, process list, game presets (Minecraft PVP, Cookie Clicker…), import/export macros & presets, Green/Blue/Red/Light themes, background image, tutorial, built-in changelog. Windows · macOS · Linux.

Launch the app

Download your system's ZIP, unzip, then launch.

Windows

  1. Download LuLuneAutoClicker-Windows.zip
  2. Unzip the archive
  3. Run Launch-Windows.vbs (recommended) or LuLuneAutoClicker.exe
  4. If SmartScreen: More info → Run anyway

macOS

  1. Download LuLuneAutoClicker-macOS.zip
  2. Unzip, then double-click Open-macOS.command
  3. Settings → Privacy → Accessibility → allow LuLune AutoClicker

Linux

  1. Download LuLuneAutoClicker-Linux.zip
  2. Unzip, then chmod +x Launch-Linux.sh and ./Launch-Linux.sh
  3. Prefer an X11 / XWayland session

macOS and Linux builds must be generated on the target machine (native mouse / keyboard modules).

Tutorials

Discord Rich Presence, logo with capital letters, and launching on each OS.

Discord Rich Presence (name + logo)

To see LuLuneAutoClicker (with capital letters) and the green logo instead of “?”.

  1. Open the Discord Developer Portal → your application.
  2. Name the application exactly LuLuneAutoClicker (General Information → Name). That is the “Playing …” title — Discord does not read it from the app.
  3. Copy the Application ID (= Client ID).
  4. Rich Presence tab → Art Assets → Upload Image. File: assets/discord-logo.png.
  5. Name the asset exactly logo (lowercase). Wait 1–2 min for Discord to propagate the image.
  6. In the app → Behavior → Discord Rich Presence: ON + paste the Client ID.
  7. Restart Discord and the app. Status: logo + LuLuneAutoClicker + Idle / Clicking.

Still lowercase? Rename the app in the Portal. Still “?”? The logo asset is not uploaded or is misnamed.

Launch on Windows

  1. Download LuLuneAutoClicker-Windows.zip then unzip
  2. Double-click Launch-Windows.vbs (no console) or LuLuneAutoClicker.exe
  3. Hotkeys: F6 start/stop · F12 panic · F7 pause

Launch on macOS

  1. Download LuLuneAutoClicker-macOS.zip then unzip
  2. Double-click Open-macOS.command
  3. Settings → Privacy → Accessibility → allow LuLune AutoClicker

Launch on Linux

  1. Download LuLuneAutoClicker-Linux.zip then unzip
  2. chmod +x Launch-Linux.sh then ./Launch-Linux.sh
  3. Prefer an X11 session (Wayland may block clicks)
