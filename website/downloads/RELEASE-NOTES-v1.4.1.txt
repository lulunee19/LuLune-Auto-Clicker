HOW TO INSTALL (short)
----------------------
  1. Download the ZIP for your OS
  2. Unzip fully (not from inside the archive)
  3. Launch:
       Windows → Launch-Windows.vbs  (or LuLuneAutoClicker.exe)
       macOS   → Open-macOS.command
       Linux   → ./Launch-Linux.sh

IMPORTANT — PERSONAL DATA
-------------------------
  The ZIP does NOT contain your stats, macros, wallpapers, or settings.
  All of that stays in each PC's user folder (AppData on Windows).
  Sharing the ZIP with a friend = a clean app with default settings.

  v1.4.1 — UI POLISH · DISCORD · OPACITY · SHORTCUTS
================================================================================

UI OPACITY (10% → 100%)
  New slider in Settings → Appearance.
  It controls the real opacity of panels, the title bar, and the
  status bar (CSS variables --panel-alpha / --chrome-alpha).
  • 10%  = very translucent UI, background ultra visible
  • 100% = solid panels
  Combines with panel blur and background image visibility.

COLORS FROM IMAGE (MAJOR FIX)
  Before: a gray photo could leave the “Start” button, borders,
  and some accents in hard-coded green because of CSS themes.
  Now:
  • Gray photo  → entire UI follows gray (buttons, toggles, glows, borders)
  • Colored photo → accents extracted from the palette
  “Custom color” option: color wheel + hue + hex to
  force an accent color that overrides theme and image.

SAFE SHORTCUT CAPTURE
  When you click to assign F6 / Panic / Pause / a macro:
  global shortcuts are temporarily unregistered.

================================================================================
  v1.4.0 — ADVANCED ENGINE (included in this build)
================================================================================

CPS RAMP
  Start at a low CPS, automatically rise to a target CPS
  over N seconds. Ideal PVP / idle warm-up.

BURST MODE
  N rapid clicks, then pause, in a loop. Controlled salvos.

PIXEL COLOR FILTER
  Only clicks if the color under the cursor matches
  (sample + tolerance). Useful for clicking a specific on-screen button.

CURSOR FAILSAFE
  Auto-stop if the mouse does not move for N seconds.

SESSION TIMER
  Stop after X minutes — avoids clicking all night.

HIGH CPS CONFIRMATION
  Dialog before starting above a threshold (e.g. 100 CPS).

SYSTEM HOTKEYS
  Panic (F12) and Pause (F7), configurable, independent of presets.

OVERLAY
  Position (4 corners) + opacity; hideable on pause.

MINIMAL UI MODE
  Keeps the essentials: start / CPS / hotkey.

LANGUAGE FR / EN
  Main interface labels.

GOALS
  Daily and/or session clicks + progress bar.

MULTIPLE BACKUPS (SLOTS)
  Several full configs without overwriting the current one.

SOUNDS / AUTO-HIDE
  Sound volume, auto-minimize window when clicking starts.
