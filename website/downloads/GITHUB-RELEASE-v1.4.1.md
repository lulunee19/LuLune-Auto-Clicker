## LuLune AutoClicker v1.4.1

Cross-platform Electron autoclicker for **Windows**, macOS, and Linux.

### Highlights
- **CPS test** with 1s / 5s / 10s / 15s / 30s / 1 min windows
- **Macros** simplified (clicks, keys, multi-key sequences, hotkeys)
- **Background images & animated GIFs** with center / position / fit controls
- **UI opacity**, image tint, custom accent color
- **Discord Rich Presence** (Client ID + `logo` asset)
- Advanced engine: CPS ramp, burst, pixel filter, failsafe, session timer
- FR/EN language (default: **English**)

### Windows download
1. Download `LuLuneAutoClicker-Windows.zip`
2. Extract fully
3. Run `Launch-Windows.vbs` (recommended) or `LuLuneAutoClicker.exe`
4. If SmartScreen appears: More info → Run anyway

Personal stats/settings stay in AppData — the ZIP does not include your data.

### Notes
- macOS / Linux builds must be packaged on those OSes (`npm run package:mac` / `package:linux`).
